# Play as Pokemon

Turn into any Pokémon in Pokopia. Only works on **Pokopia 2.0.0, update 655360**.

## Install

- **Emulator:** unzip into your emulator's `load` folder. Then right-click Pokopia, open **Properties → Add-Ons**, and tick **Play as Pokemon**.
- **Switch with custom firmware:** unzip onto the root of the SD card (untested).

## Buttons

| Hold | Does |
|---|---|
| ZL + D-pad Left | Turn into the Pokémon |
| ZL + D-pad Right | Turn back into your character |
| ZR (as a flying Pokémon) | Take off, hold to rise |
| ZL (while flying) | Go down. Keep holding on the ground to land |
| ZL + ZR (while flying) | Drop out of the air |

## Change the Pokémon

You turn into **Ditto** unless you change it. To pick a different Pokémon:

1. Open the file `76A489F3BD3642FA.txt` in Notepad. It is in the `cheats` folder you unzipped.
2. Near the top, find this line:

   ```
   020F0000 03D14C06 00000046
   ```

3. Change **only the last 8 characters**, `00000046`, to the code of your Pokémon from the list below.
   For example, for Pikachu the line becomes:

   ```
   020F0000 03D14C06 00000002
   ```

4. Save the file and restart the game.

`00000046` is Ditto, so change it back to that to go back to Ditto.
