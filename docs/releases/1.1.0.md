# Pokopia Editor for Linux 1.1.0

Linux release 1.1.0, based on upstream editor 1.9.2. The local 1.1.1–1.1.4 filenames
were trial builds of these features; this is their combined public release.

## Install and open

Download `PokopiaEditor-1.1.0-x86_64.AppImage` from this release, then run:

```sh
chmod +x PokopiaEditor-1.1.0-x86_64.AppImage
./PokopiaEditor-1.1.0-x86_64.AppImage
```

Built on Ubuntu 26.10 x86_64; requires glibc 2.44. Older distributions are unverified.
If FUSE is unavailable, try `./PokopiaEditor-1.1.0-x86_64.AppImage --appimage-extract-and-run`.
Close older editor instances first; preserve unsaved edits with **Save copy**.
Back up your save and close the emulator before editing its on-disk save.

## Features and instructions

| Feature | How to use it |
| --- | --- |
| Remember tool settings | Reopen the editor to restore the last page, brushes, filters, height options, map view and tool choices. Preferences save when switching pages and closing. Save edits are not automatically saved. |
| Tile contents with catalog icons | With **Select**, click a tile, then its stack badge. Browse objects and terrain in the icon grid, filter by Y height, and choose **Select on map**. Terrain reveals its level; an object becomes selected for editing. |
| Glowing Block markers | Enable **Map overlays → Glowing Blocks**. Click a gold star to inspect its tile and height. These are read-only saved positions; reload after an in-game save. The contents of unopened blocks remain unknown. |
| Raise objects with terrain | In **Ground height**, enable **Move objects and placed items up**. **Raise** and the raising part of **Flatten** lift obstructing objects and their stacks while preserving horizontal positions. The choice is remembered. |
| Rectangular height edits | Choose **Ground height → Raise, Lower or Flatten**. Hold **Shift + left-drag** to mark a rectangle; release to apply. For Flatten, set the target Y first. **Esc** cancels before release. |
| Spacebar panning | With the pointer over the map, hold **Space + left-drag** to pan with any tool, even after changing a sidebar control. Release Space to resume editing. Middle-drag also pans. |
| Rectangular painting | In **Paint ground**, choose a block, then **Shift + left-drag** a rectangle. Release to paint; **Esc** cancels before release. Ordinary dragging still uses the chosen brush shape. |
| Paint underlying layers | Enable **Paint ground → Paint all terrain layers below**, above **Brush shape**. Brushes and rectangles paint existing terrain from the visible surface downward. The choice is remembered. |

Height and paint rectangles use inclusive cell boundaries and show dimensions while
dragging. Each rectangle is one undo step. Object lifting and its terrain edits undo
together. A blocked object destination cancels the stroke.

## Limits and known issues

- Deep painting preserves bedrock, liquids, air, objects and buried building blocks.
  It replaces terrain materials, including resource terrain such as ore. Use **Save copy**
  to try an edit before replacing your active save. A height cutoff limits painting
  to the revealed surface and terrain below it.
- Object lifting does not move loose dropped collectibles or Glowing Blocks.
  Lowering terrain leaves objects at their existing height.
- Glowing Block parsing was checked against one spot before breaking, after
  breaking and after collecting a disc. Other markers still need in-game testing.
  Reward prediction and additional table fields remain undecoded.
- **Cut and Rock Smash while transformed** may fail with Pikachu and other forms.
  Live transformation worked in the Linux gameplay trial. Returning to the normal
  character is the suggested workaround, but that workaround is not yet verified.
- Experimental live memory editing is limited to the verified Pokopia 2.0.0 build.
  Launch Lichii through **Mods → Launch emulator** and keep the editor open to retain
  memory access under Linux's parent-process policy.

## Validation

28 automated tests passed, including rectangle controls, protected terrain layers,
object stack lifting, preferences and spacebar focus behavior. Save-backup checks
covered deep painting, object lifting, encoding validation, undo and redo without
writing the original save. UI checks covered the new controls and preference
restoration. These checks do not establish compatibility with every game state
or Linux distribution.
